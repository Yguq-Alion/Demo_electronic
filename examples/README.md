# Примеры результата

Файлы `result-*.json` здесь — примеры карточек для товаров из `data/products/`,
упоминаются в README (раздел «Пример результата»).

Генерация (нужен настроенный `.env` с ключом):

```
python scripts/generate_examples.py
```

Скрипт прогоняет каждый товар через сервис и записывает `result-<имя-товара>.json`.
